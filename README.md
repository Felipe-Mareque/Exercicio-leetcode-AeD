# Exercicio-leetcode-AeD
Aluno: Felipe Reichow Mareque; 
Turma: M1;

Assunto: questão 498 do leetcode sobre diagonais em matrizes.

Nesse exercício, o objetivo foi percorrer uma matriz (uma tabela de números) fazendo um caminho de zigue-zague pelas diagonais. 
O foco aqui foi treinar a lógica para controlar a posição ("onde estou") e a direção ("para onde vou") dentro do código, sem deixar nada sair do trilho.
 O que aprendi com isso:
 Foi dificil para fazer o código entender que chegou na "parede" da matriz. 
 Precisei garantir que ele mudasse de direção no momento exato, evitando erros de acesso à memória.
Criei uma forma do programa alternar entre subir e descer as diagonais de forma automática a cada passo do caminho.
